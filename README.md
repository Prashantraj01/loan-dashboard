# Credit Risk & Loan Default Analysis Dashboard

Developed an end-to-end Credit Risk & Loan Default Analysis Dashboard using Microsoft Power BI to analyze customer repayment behavior, financial risk patterns, and loan default trends.

Integrated data from SQL Server and automated ETL workflows using Power BI Dataflows and Power Query for scalable data processing. Implemented advanced DAX measures, calculated KPIs, and interactive visualizations including slicers, filters, drill-through analysis, donut charts, and multi-row cards.

The dashboard enables risk profiling, credit score analysis, repayment monitoring, and business performance tracking to support data-driven financial decision-making.

## Technologies Used
- Microsoft Power BI
- SQL Server
- Power BI Dataflow
- Power Query
- DAX
